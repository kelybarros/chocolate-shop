# Chocolate Shop

Landing page desenvolvida para uma marca fictícia de chocolates, com foco em composição visual, animações e interatividade.

## Tecnologias

- React.js
- JavaScript
- Tailwind CSS
- GSAP
- ScrollTrigger
- Vite

## Implementação

- Animações controladas por GSAP.
- Efeitos de movimento vinculados à rolagem com ScrollTrigger.
- Seções interativas.
- Layout responsivo para diferentes tamanhos de tela.
- Imagens de produtos geradas com auxílio de inteligência artificial.

## Execução local

Instale as dependências:

```bash
pnpm install
```

Inicie o ambiente de desenvolvimento:

```bash
pnpm dev
```

Gere a versão de produção:

```bash
pnpm build
```
